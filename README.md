# VBank

VBank — учебная виртуальная банковская система для учёта денежных средств пользователей, ведения счетов, выполнения внутренних операций и обработки заявок.

## Общая идея

VBank моделирует замкнутую банковскую среду, в которой все действия выполняются внутри одной системы и по единым правилам.

Основу проекта составляют:
- пользователи;
- счета;
- операции;
- заявки;
- справочники;
- правила работы системы.

Система охватывает:
- регистрацию и вход пользователей;
- ведение пользователей и их статусов;
- открытие и сопровождение счетов;
- внутренние операции по счетам;
- обработку заявок;
- ведение журнала значимых действий.

## Роли участников

В системе предусмотрены три роли:
- `Client` — использует систему для работы со своими данными и счетами;
- `Operator` — обрабатывает заявки и выполняет служебные действия;
- `Admin` — управляет правилами и справочными сущностями системы.

У пользователя в каждый момент времени одна активная роль.
